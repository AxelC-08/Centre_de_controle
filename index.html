Schéma SQLite

Le fichier autonome jeux_schema.sql contient la création de la table et les INSERT des jeux extraits ci-dessus. Les champs numériques sont NULL si la source n’indique pas de valeur numérique. Les libellés source (par exemple « Beaucoup », « Variable », « Dépend ») sont conservés séparément.

id — identifiant unique (INTEGER PRIMARY KEY)

name — nom du jeu (TEXT, obligatoire)

players_min / players_max — bornes numériques (INTEGER, NULL si inconnue / sans borne)

players_label — libellé source des joueurs (TEXT)

duration_min_minutes / duration_max_minutes — durée en minutes (INTEGER, nullable)

duration_label — texte de durée de la source (TEXT)

card_count — nombre de cartes numérique (INTEGER, nullable)

card_label — précision source, notamment si non numérique (TEXT)

rating — note sur 5 (REAL, nullable)

rating_label — affichage d’origine de la note (TEXT)

Créer la base de données

Depuis le dossier où se trouve jeux_schema.sql, exécutez cette commande avec SQLite installé :

sqlite3 jeux.db < jeux_schema.sql

Cette commande crée/remplit jeux.db. Pour vérifier le nombre de lignes : sqlite3 jeux.db "SELECT COUNT(*) FROM games;". Pour consulter le catalogue : sqlite3 -header -column jeux.db "SELECT name, players_label, duration_label, rating FROM games ORDER BY name;".

DDL de la table

                CREATE TABLE IF NOT EXISTS games (
                id INTEGER PRIMARY KEY,
                name TEXT NOT NULL,
                players_min INTEGER CHECK (players_min IS NULL OR players_min >= 0),
                players_max INTEGER CHECK (players_max IS NULL OR players_max >= 0),
                players_label TEXT,
                duration_min_minutes INTEGER CHECK (duration_min_minutes IS NULL OR duration_min_minutes >= 0),
                duration_max_minutes INTEGER CHECK (duration_max_minutes IS NULL OR duration_max_minutes >= 0),
                duration_label TEXT,
                card_count INTEGER CHECK (card_count IS NULL OR card_count >= 0),
                card_label TEXT,
                rating REAL CHECK (rating IS NULL OR (rating >= 0 AND rating <= 5)),
                rating_label TEXT
                );

Le DDL ci-dessus est documenté pour consultation ; le fichier SQL autonome est la source exécutable qui inclut aussi les données.
